00 Cover - Roadmap Scope

repo-derived

LunaCrypto Research Workstation

Logged-in AI crypto research workstation. The browser talks only to the NestJS API, research artifacts stay inspectable, and the product never presents itself as an execution terminal.

Market context Deterministic signals Multi-agent research Structured thesis User journal

Web UI

Routes, workstation layout, command rail, evidence surfaces.

NestJS API

Auth headers, workspace boundary, product REST contracts.

Jobs / Queue

Inline, memory, and future BullMQ status projection.

Python Engine

Agents, SignalEngine, providers, thesis builder.

Journal DB

Runs, events, theses, signals, briefs, alerts, reviews.

Read APIs

Typed DTOs for web screens and audit drawers.

Non-negotiable product rules

P0

Every thesis screen shows evidence, contradictions, freshness, missing data, confidence, invalidation, and monitor-next near the decision surface.

Every AI output remains inspectable through run IDs, thesis IDs, signal IDs, source timestamps, payload drawers, and timeline events.

Use research language: Run research, Watch, Review, Record decision, Scenario active, Invalidation risk.

Keep the surface focused on thesis quality, evidence trails, invalidation, and review discipline.
